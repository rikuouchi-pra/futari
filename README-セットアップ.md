# ふたりのリスト 単独アプリ版（PWA）セットアップ

Claudeを使わずに動く版です。データはFirebase（Googleのクラウドデータベース）に保存します。夫婦2人の利用なら無料枠に収まる見込みです。

## 1. Firebaseプロジェクトを作る（スマホのブラウザでもできます）

1. https://console.firebase.google.com を開き、rikurussel14@gmail.com でログインします。
2. 「プロジェクトを作成」を押します。名前は例えば `futari-list` にし、Googleアナリティクスはオフにします。
3. 左メニュー「構築 → Authentication」→「始める」→「メール/パスワード」を有効にして保存します。
4. 左メニュー「構築 → Firestore Database」→「データベースを作成」を押します。
   - ロケーション：`asia-northeast1（東京）`
   - モード：本番環境モード
5. Firestoreの「ルール」タブを開き、同梱の `firestore.rules` の中身をすべて貼り付けて「公開」を押します。
   - このルールで、読み書きできるのはふたりのメールアドレスだけになります。
   - 「じぶん」の項目は、書いた本人しか読めません。
6. 歯車 →「プロジェクトの設定」→「マイアプリ」→ `</>`（ウェブ）を押し、名前を付けて登録します。
   - 表示される `firebaseConfig` の中身（apiKey〜appId）を `config.js` に貼り付けます。
   - Claudeに送ってもらえれば、こちらで書き換えたファイルを返します。
   - この設定は秘密情報ではありません。守りは5のルールが担います。

## 2. インターネットに公開する（どちらか一つ）

### A. スマホだけでやる：GitHub Pages

1. https://github.com でアカウントを作り（無料）、「New repository」を押します。名前は例えば `futari` にし、Public を選びます。
   - 公開されるのはアプリのプログラムだけで、データは含まれません。
2. 「uploading an existing file」から、このフォルダのファイルを**すべて**アップロードします。
3. 「Settings → Pages」を開き、Branch を `main`、フォルダを `/ (root)` にして保存します。
4. 数分後、`https://ユーザー名.github.io/futari/` で開けるようになります。
5. Firebaseの「Authentication → 設定 → 承認済みドメイン」に `ユーザー名.github.io` を追加します。

### B. パソコンがある場合：Firebase Hosting

```
npm install -g firebase-tools
firebase login
cd このフォルダ
firebase deploy --only hosting,firestore:rules --project プロジェクトID
```

公開先は `https://プロジェクトID.web.app` です。この方法では、ルールも同時に反映されます。

## 3. iPhoneに入れる（夫婦それぞれ）

1. 公開したURLをSafariで開きます。
2. 自分のメールアドレスとパスワードを入れ、「はじめて使う（登録）」を押します。
3. 共有ボタン →「ホーム画面に追加」を押します。以後はホーム画面のアイコンから開きます。

## 4. Claude版から引っ越す（夫婦それぞれ）

1. **Claude版**で「設定 → 単独アプリ版への引っ越し → 引っ越しデータを書き出す」を押し、「ファイル」アプリに保存します。
2. **単独アプリ版**で「設定 → Claude版からの引っ越し → 引っ越しデータを読み込む」を押し、1のファイルを選びます。
3. 夫が先に読み込むと、ふたりの項目・家計の設定・写真が移ります。そのあと妻が自分のファイルを読み込むと、妻の「じぶん」の項目と設定が移ります。

- すでにある項目は上書きされません。同じファイルを2回読み込んでも重複しません。

## いまの版でできないこと（今後対応）

- **Googleカレンダーの自動同期**：CSVの書き出しは使えます。
- **レシートの読み取り**：6のAI設定をすると、写真から自動で読み取ります。設定前は、端末内のかんたんな読み取り（文字を貼り付けた場合のみ）で動きます。
- **「不具合を送る」からの自動修正**：単独アプリ版では自動修正はありません。

## 容量の目安（Firebase無料枠）

- 保存容量は1GBです。写真は1枚900KB以下に縮小して保存し、アプリでは700MBを上限として表示します。
- 1日あたり、読み取り5万回・書き込み2万回まで使えます。

## 5. Googleカレンダー連携（Google Apps Script）

同期は夫婦それぞれ、**自分のGoogleアカウント**の自分のカレンダーとだけ行います。同じ作業を夫と妻で1回ずつ、自分のアカウントで行ってください。

1. https://script.google.com を**自分の**Googleアカウントで開き、「新しいプロジェクト」を作ります。
2. `Code.gs` の中身をすべて消し、同梱の `gas/Code.gs` を貼り付けて保存します。
3. 左の「サービス ＋」→「Google Calendar API」→「追加」を押します。
4. 関数 `setupTest` を選んで「実行」→「権限を確認」→ 自分のアカウント →「詳細」→「（安全ではないページ）に移動」→「許可」の順に進めます。
   - ログに「OK」と出れば準備完了です。
5. 「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 表示された URL（…/exec）をコピーします。
6. GitHub の `config.js` を鉛筆で編集し、`FUTARI_GAS_URLS` の自分のメールアドレスの "" に 5 のURLを貼り付けて Commit します。

**使い方**：「じぶん › 予定」の「⟳ 今すぐ同期」を押すと、その場で自分のGoogleカレンダーに反映されます。自動で同期されるのは次の2つです。
- アプリを開いている間、予定を追加・変更したとき（数秒後）
- アプリを開いている間の5分ごと

## 6. AI（Gemini）で写真を読み取る（勤務表・レシート）

5のApps Scriptに、Geminiを使う設定を足します。**夫の分だけでOK**です（妻のアプリからも使えます）。

1. https://aistudio.google.com を開き、Googleアカウントでログインします。
2. 「Get API key」→「APIキーを作成」を押し、表示されたキー（AIza…）をコピーします。無料で、カードの登録はいりません。
3. Apps Script の `Code.gs` を、同梱の新しい `gas/Code.gs` にすべて貼り替えて保存します。
4. 左の歯車「プロジェクトの設定」→ 一番下「スクリプト プロパティ」→「スクリプト プロパティを追加」を押します。
   - プロパティ：`GEMINI_API_KEY`
   - 値：2 のキー
5. 関数 `setupTest` を選んで「実行」を押します。外部への接続の許可を求められたら「許可」します。
6. 「デプロイ → デプロイを管理 → 鉛筆 → バージョン：新バージョン → デプロイ」の順に押します。URLは変わりません。
7. Safariで `…/exec?diag=1` を開き、`"gemini":"OK（…）"` と出れば完了です。

**使い方**
- 勤務表：カレンダー ›「シフト入力」→「勤務表の写真から読み取る」
- レシート：出費 ›「レシートで実績登録」

**注意**
- 無料枠のAPIでは、送った写真や文章がGoogleのサービス改善に使われることがあります。
- 写真はアプリのデータベースに数秒だけ置き、読み取りが終わると消します。
